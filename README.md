# ОтличийНет

Учебный проект для сравнения нескольких файлов на схожесть. Окно и веб-страница только показывают результат. Само сравнение пишется в ядре.

## Структура

- `core/analysis.py` — режимы и класс, в котором будет сравнение;
- `core/report.py` — отчёт по уже посчитанному результату;
- `core/config.py` — настройки, в том числе ключ Gemini;
- `gui/app.py` — окно на PySide6;
- `web/app.py` и `web/templates/index.html` — страница на Flask.

## Запуск

Библиотеки ставятся в обычный Python:

```powershell
py -m pip install Flask PySide6
```

Из корня проекта:

```powershell
py -m gui.app
py -m web.app
```

Окно пока пустое. Страница открывается по адресу `http://127.0.0.1:5000/`.
